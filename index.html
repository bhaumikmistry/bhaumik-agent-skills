7 SKILLS · CLAUDE CODE · MIT

Seven working methods,
written down so they survive the session.

A skill is not a prompt. It is a procedure with an order, a set of rules it refuses to break, and a record of what went wrong last time. These are the ones that earned their place by being used more than once.

$ npx skills add bhaumikmistry/bhaumik-agent-skills
WHAT THIS IS

An agent that forgets everything is only ever as good as its last instruction.

Every one of these started as the same conversation happening for the third time. A skill is where that conversation stops being retyped: the order the steps go in, the check that is not optional, the mistake that was made once and is now written into the procedure so it is not made again.

They install into Claude Code as a plugin and fire on what you actually say, rather than on a command you have to remember.

A fixed order

Most of these refuse to start at the interesting step. The gameweek skill will not plan a transfer until last week is on the record, because planning first is just chasing scores.

A stated refusal

Each one names the thing it will not do. That is usually the part carrying the value, and it is always the part learned the expensive way.

A record that outlives the chat

Ledgers, retrospectives, design notes. If the reasoning only exists in a conversation, the next session re-derives it and gets a different answer.

THE SKILLS

Seven of them, and what each one refuses to do.

01 · v1.1.0

ui-craft

Build interfaces that do not read as agent-generated.
FIRES ONa new page, a redesign, “make this look better”

Reaches for shadcn/ui before writing anything by hand, retheming what it takes to the project's own tokens rather than pasting defaults. Runs Impeccable's deterministic detector over the result, then publishes anything built twice to a registry so it installs by name next time.

THE RULE IT WILL NOT BENDRendering the page is the check. The detector is a linter and will pass a page with visibly broken controls, because it never opens one.
references/ impeccable · new-component · shadcn
02

fpl-gameweek

Run a Fantasy Premier League season as a ledger rather than a hunch.
FIRES ONtransfers, captaincy, chips, “predict next team”

Pulls live data, projects three ranked plans at no hit, minus four and minus eight, then scores every one of them against the real result once the gameweek settles, including the plans that were never played. Studies what the league leaders did differently with their chips stripped out.

THE RULE IT WILL NOT BENDPlanning is the last step, not the first. Without last week's opposition read on the record it refuses to plan, because the alternative is chasing scores.
references/ dashboard · data-sources · ledger · opposition · projection · rules · scoring · strategy
03 · v2.0.0

architecture-map

Turn a system into a place you can walk around.
FIRES ON“how does this fit together”, onboarding, a system diagram

Takes a repository, a design doc or a rough idea and renders an isometric city: buildings sized by weight, lines that are real call paths, moving dots that are payloads. One self-contained page, zoomable, click-to-inspect.

THE RULE IT WILL NOT BENDSynthesise the understanding first and render it second. A diagram drawn straight from a file listing shows the folders, not the system.
references/ knowledge-doc · rendering
04

coach

Communication coaching, in four modes.
FIRES ON“help me write”, “how does this sound”, “coach me”

Drafts messages, reviews them against a set of stated commitments, reads back over past conversations for patterns, and prepares for the conversation nobody wants to have.

THE RULE IT WILL NOT BENDFront-load the context before asking for input, and name the impasse rather than routing around it.
05

interviewer

Keep an async interview series moving.
FIRES ON“draft outreach”, “next question”, “follow up with”

Drafts the approach, shapes questions that earn a real answer instead of a press release, chases politely, and holds the pipeline so nobody is left on read for three weeks.

THE RULE IT WILL NOT BENDOne question at a time. A list of six arrives as homework and gets answered like homework.
06

not-ai

Strip the tells out of writing.
FIRES ON“de-AI this”, “sounds generated”, “too robotic”

Works from a catalogue of the patterns that give machine prose away: elaborate verbs where a plain one would do, the rule of three, negative parallelism, hedge-then-assert, and the closing sentence about significance that says nothing.

THE RULE IT WILL NOT BENDSpecific beats smooth. One odd true detail is worth more than a paragraph that reads well and asserts nothing.
07

arsenal-match-writeup

Write up a match without inventing any of it.
FIRES ON“we just played”, “match report”, “update the tracker”

Produces a verified post for the site and updates the fixture tracker in the same pass, so the write-up and the record cannot disagree with each other.

THE RULE IT WILL NOT BENDEvery scoreline, scorer and minute is checked against a source before it is written. Recalled football is confidently wrong football.
BUILT WITH UI-CRAFT

Four landing pages, four briefs, no visual direction given.

The ui-craft skill was tested by handing four agents four unrelated products and telling them nothing about how the pages should look. The risk was that all four would converge on the same warm-cream-and-serif default that generated interfaces reliably produce.

They did not. Four directions, four typefaces, and every one of them traceable to something true about its subject. Each page below is rendered live from this repository — they are static files in examples/, not screenshots.

The brief's real problem was not weather, it was that nobody knows who decided what. So the hero is a dated, signed call-off notice and the accountability log is a section rather than a footnote.

HOW A SKILL IS PUT TOGETHER

One file that always loads, and references that load when they are needed.

SKILL.md carries the frontmatter the router reads and the procedure the agent follows. Anything long enough to be a distraction on every invocation — a schema, a catalogue, a scoring method — goes into references/ and is read only when that step is reached.
