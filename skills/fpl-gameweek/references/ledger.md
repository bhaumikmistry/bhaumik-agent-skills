# Ledger shapes

Everything under `data/`. The build script globs `GW*.json` in each directory and merges by gameweek number, so adding a gameweek is just dropping in a file.

```
data/
  projections/GW{N}.json   written before the deadline
  actuals/GW{N}.json       written after the gameweek settles
  leagues/GW{N}.json       generated by scripts/league_study.py
  analysis/GW{N}.json      written by hand - the reading of the league data
  retro/GW{N}.md           the retrospective write-up
  retro/model-adjustments.md   log of weighting changes and why
```

Player rows inside a plan squad:

```json
{"player": "De Cuyper", "id": 115, "pos": "DEF", "club": "BHA", "price": 4.5,
 "starting": true, "fixture": "CHE(A)", "fdr": 4, "fdr5": 3.0,
 "confidence": 68, "xp": 3.2, "incoming": true,
 "reason": "why this player, from last season's record and the fixture",
 "minutes": 77, "points": 17, "autosub_in": false, "counted": true}
```

`minutes`, `points`, `autosub_in`, `autosub_out` and `counted` are written back by the scorer after the gameweek. `captain` / `vice_captain` booleans sit on the player row. `flag: true` draws the rust stripe for a doubtful player; `incoming: true` outlines a signing in green.

## leagues/GW{N}.json — the generated parts worth knowing

```json
{
  "squads_studied": 11,
  "player_board": [
    {"player": "Szoboszlai", "club": "LIV", "pos": "MID", "price": 7.0, "points": 8,
     "own": 42.1, "held_by": 8, "held_pct": 73, "captained_by": 0,
     "mine": false, "delivered": 64}
  ],
  "delivered_not_mine": [],
  "delivered_mine": [],
  "table": [], "chip_usage": [], "captain_choices": [], "most_missed": [], "studies": []
}
```

`delivered` is `held_by × points` — consensus times return. `held_by` counts distinct squads, so a manager topping two leagues counts once.

## analysis — the reading blocks

Alongside the finding lists, the analysis carries `who_delivered` with `signals[]` (the board entries worth acting on, each with a `read`), `ours_that_delivered[]` (edges to protect), and a `conclusion`.

The dashboard renders `headline`, `summary`, both finding lists, `who_delivered`, the caveats block, and the actions list. `leagues/GW{N}.json` is generated — never hand-edit it; re-run the script instead.
