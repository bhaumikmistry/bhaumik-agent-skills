# Interview Pipeline Reference

The live target list is maintained at:
```
~/mac-workspace/assist/people/interviews/target-list.md
```

Individual interview files are at:
```
~/mac-workspace/assist/people/interviews/<name>-interview.md
```

## Pipeline stages

| Status | Meaning |
|--------|---------|
| 🆕 Target | Identified, not yet reached out |
| 📤 Outreach sent | Cold email/DM sent, waiting |
| 📤 Intro via [person] | Warm intro in progress |
| 🟡 Replied, Q1 ready | They agreed, send first question |
| 🟡 In progress | Active back-and-forth |
| ⏸️ Paused | Busy, follow up later (note the date) |
| ✅ Complete | All questions answered |
| ❌ Declined | Closed, door may be open later |

## Interview file structure

Each target gets a file with:
- About (name, location, contact, handles)
- Career history (concise)
- Why interview (the tensions, the interesting angles)
- Question trajectory (planned arc if drafted)
- Outreach email draft (if prepared)
- Interview Q&A (as answers come in)
- Status tracker (checkboxes)

## When adding a new target

1. Create `~/mac-workspace/assist/people/interviews/<name>-interview.md`
2. Add them to the target list table
3. Research: LinkedIn, blog, Twitter, any public writing
4. Identify 2-3 tensions/contradictions in their path
5. Draft outreach following [outreach.md](../outreach.md)
